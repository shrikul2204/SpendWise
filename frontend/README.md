# 💰 SpendWise – AI-Based Budget Tracker

SpendWise is a full-stack AI-powered budget management web application that helps users track income and expenses, analyze spending patterns, and receive smart financial insights.

## 🚀 Features

- 🔐 User Authentication (JWT-based Login & Signup)
- 💰 Add Income and Expenses
- 📊 Dashboard with Total Income, Expense & Balance
- 🤖 AI-based Financial Insights & Predictions
- 📋 Income & Expense History (Tables)
- 🧠 Smart Transaction Analysis
- 🎨 Modern Responsive UI (React)

## 🛠️ Tech Stack

### Frontend
- React.js
- Axios
- CSS (Custom UI Design)

### Backend
- Node.js
- Express.js
- MySQL
- JWT Authentication

## 🏗️ Project Architecture

Frontend → API Requests → Backend (Express) → MySQL Database
